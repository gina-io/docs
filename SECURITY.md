# Security policy

This policy covers this repository and the documentation site it builds, <https://gina.io/docs/>, including the Cloudflare Worker in `infra/cloudflare/`.

## Reporting a vulnerability

Please report security issues privately through GitHub, not in a public issue:
<https://github.com/gina-io/docs/security/advisories/new>

A vulnerability in the gina framework itself goes through the framework's own policy:
<https://github.com/gina-io/gina/security/policy>
