# Jinja2 Parity

This page lists exactly what `@rhinostone/swig-jinja2` accepts — operators, tags, filters, and is-tests — cross-referenced against Python Jinja2 3.x and the native `@rhinostone/swig` frontend.

The matrices below are ground truth: each row maps to a symbol actually exported by the shipped source, and every filter and is-test was cross-checked against Jinja2 3.x. Outputs match the reference except where the JavaScript runtime forces a divergence — those are flagged here and detailed under [Behavioural differences](#behavioural-differences). For features that throw at parse time, see [Non-Goals](./non-goals).

## Operators

| Operator | Shape | Semantics | Lowering / notes |
| --- | --- | --- | --- |
| `**` | `a ** b` | Power. A function or filter result that is `undefined` or `null`, or a subscript that finds nothing, gives `NaN` (`fn() ** 2`), where a missing variable reads as `""` (`x ** 2` gives `0`). | `Math.pow(a, b)` |
| `//` | `a // b` | Floor division. | `Math.floor(a / b)` |
| `~` | `a ~ b` | String concatenation. Coerces both sides to strings. A missing or `null` variable reads as `""`, and since 2.9.10 so does a subscript that finds nothing: `arr[0] ~ "x"` gives `x` when `arr` is empty, as in Jinja2 (before, `undefinedx`). Since 2.9.13 so does a function or filter result that is `undefined` or `null`, here and at an arithmetic or unary operand: `fn() ~ "x"` gives `x` (before, `undefinedx` or `nullx`), where Jinja2 writes `None` for any `None` operand (`Nonex`). | `(String(a) + String(b))` |
| `+` `-` `*` `/` `%` | `a + b` | Arithmetic. `+` also concatenates when either side is a string (JavaScript coercion). | See [Behavioural differences](#behavioural-differences) for `+` on mixed types. |
| `a if c else b` | inline conditional | Returns `a` when `c` is truthy, else `b`. The `else` arm is optional (`a if c` yields `""` when `c` is falsy). | |
| `in` / `not in` | `x in seq`, `x not in seq` | Membership, as in Jinja2 (since 2.9.0): a list holds an equal item, a string a substring, a mapping a key. A test Jinja2 cannot run, such as a number as the container, is false for `in` and true for `not in`. Some answers still differ from Jinja2 — see [Behavioural differences](#behavioural-differences). | `_utils.isIn(x, seq, "python")`; `not in` binds at the same level as `in`. |
| `and` `or` `not` | logic | Short-circuit boolean logic. | |
| `==` `!=` `<` `>` `<=` `>=` | comparison | Standard comparisons. | |
| `seq[start:stop:step]` | slicing | Python slice semantics — negative indices count from the end, `step` walks, `[::-1]` reverses. | Strings slice to strings, arrays to arrays. |
| `is` / `is not` | `x is <test>` | Predicate. Routes through `_ext._test_<name>(subject, ...args)`. | See [is-tests](#is-tests). |

Operators bind as in Jinja2, loosest first: the inline `if`/`else`; `or`; `and`; `not`; the comparisons, `in` and `not in`; `+` and `-`; `~`; `*`, `/`, `//` and `%`; `**`, read from the left; filters and `is` tests; the unary `-` and `+`; then attribute access, subscripts and calls. So `not x == y` is `not (x == y)`, `{{ 1 + 2 is number }}` tests `2`, `{{ -x|abs }}` is the absolute value of `-x`, `-2 ** 2` is `4` and `2 ** 3 ** 2` is `64`. These levels hold since 2.8.2. Unlike Jinja2, comparisons do not chain: `==` and `!=` bind more loosely than `<`, `>`, `<=`, `>=` and `in`, and each level groups from the left, so `3 > 2 > 1` is `(3 > 2) > 1`, which is false, where Jinja2 reads it as `3 > 2 and 2 > 1`.

Jinja2's global functions — `range()`, `dict()`, `cycler()`, `joiner()`, `lipsum()`, `namespace()` — are **not** exposed (see [Non-Goals](./non-goals#other-known-gaps)). To iterate a count, pass an array in locals or write a literal `{% for i in [1, 2, 3] %}`.

## Whitespace control

`{{- … -}}` and `{%- … -%}` strip surrounding whitespace at chunk boundaries — same shape as Python Jinja2's `trim_blocks`/`lstrip_blocks`-adjacent minus markers.

| Marker | Effect |
| --- | --- |
| `{{- foo }}` | Strip the preceding chunk's trailing whitespace. |
| `{{ foo -}}` | Strip the following chunk's leading whitespace. |
| `{{- foo -}}` | Strip both. |
| `{%- if … %}` / `{%- endif %}` | Same, on tag-statement boundaries. |

The semantics match native swig: a `{%- endtag %}` strips trailing whitespace of the immediately enclosing tag's last child only, not deeper. See [native swig syntax → Whitespace control](../swig/syntax#whitespace-control); both frontends are consistent.

## `is` tests {#is-tests}

`is <test>` and `is not <test>` route through the `_ext._test_<name>` slot. The Jinja2 constructor registers the 18 built-ins below via `setExtension`:

| Test | Shape | Semantics |
| --- | --- | --- |
| `defined` | `x is defined` | `true` if `x` is defined and not `null`. |
| `undefined` | `x is undefined` | `true` if `x` is undefined or `null`. |
| `none` | `x is none` | `true` if `x` is `null` or `undefined`. |
| `even` | `x is even` | `true` if `x` is an even integer. |
| `odd` | `x is odd` | `true` if `x` is an odd integer, a negative one included (Python's `x % 2 == 1`). |
| `divisibleby` | `x is divisibleby(n)` or `x is divisibleby n` | `true` if `x` is a number, `n` a non-zero number and `x % n === 0`. |
| `iterable` | `x is iterable` | `true` if `x` is an array, a string or an object. |
| `mapping` | `x is mapping` | `true` if `x` is a plain object. |
| `sequence` | `x is sequence` | `true` if `x` is an array or a string. |
| `string` | `x is string` | `typeof x === 'string'`. |
| `number` | `x is number` | `typeof x === 'number'`, so `NaN` and the infinities count. |
| `boolean` | `x is boolean` | `typeof x === 'boolean'`. |
| `true` | `x is true` | `true` only for the boolean `true` (`x === true`), as Python's `x is True`, so `1 is true` is false (since 2.9.9). |
| `false` | `x is false` | `true` only for the boolean `false` (`x === false`), so `0 is false` is false (since 2.9.9). |
| `callable` | `x is callable` | `typeof x === 'function'`. |
| `lower` | `x is lower` | `true` if `x` is a string with at least one cased letter and no uppercase or titlecase letter, as Python's `str.islower`. |
| `upper` | `x is upper` | `true` if `x` is a string with at least one cased letter and no lowercase or titlecase letter, as Python's `str.isupper`. |
| `sameas` | `x is sameas(other)` or `x is sameas other` | Strict identity (`===`). |

`defined`, `undefined`, and `none` on a bare variable are compiled through the `IRVarRefExists` IR node so the defined/undefined signal survives (the default variable lookup coerces missing context slots to empty strings, which would wash out the test).

A test takes its one argument with or without parentheses, as in Jinja2 (since 2.8.2): `x is divisibleby 3`, `x is sameas false`. On `null`, an undefined variable, a boolean, or a value a test is not meant for, some tests answer differently from Jinja2 — see [Behavioural differences](#behavioural-differences).

Jinja2's `integer` and `float` tests are **not** registered — JavaScript has a single `number` type, so `5` and `5.0` are indistinguishable. `x is integer` / `x is float` evaluate to `false`; use `x is number` instead.

Register additional tests by exposing them on `_ext._test_<name>`:

```js
var jinja2 = require('@rhinostone/swig-jinja2');
jinja2.setExtension('_test_positive', function (x) { return typeof x === 'number' && x > 0; });
jinja2.render('{{ "yes" if n is positive else "no" }}', { locals: { n: 3 } });
// → "yes"
```

## Tags

`@rhinostone/swig-jinja2` ships 13 built-in tag families (`elif` and `else` are branch markers consumed by `if`/`for`, not standalone tags). Each is registered in `packages/swig-jinja2/lib/tags/index.js`.

| Tag | Ends | Notes |
| --- | --- | --- |
| `set` | No¹ | `{% set x = 5 %}`, expression RHS, and body form `{% set x %}…{% endset %}`. Dotted LHS (`set obj.k`) is supported; bracket-notation LHS throws — see [Non-Goals](./non-goals#bracket-notation-set). |
| `if` / `elif` / `else` / `endif` | Yes | Full multi-branch conditionals, including `elif` chains. |
| `for` / `else` / `endfor` | Yes | `loop.index`/`index0`/`first`/`last`/`length` and empty-fallback `{% else %}`. Loop filters work as in Jinja2 (since 2.9.4): `{% for x in xs if x > 1 %}` keeps the items the test holds for, the test sees the loop variables and the enclosing `loop`, and `loop.index`, `loop.length`, `loop.last` and the `{% else %}` branch count only the kept items. One loop variable over a mapping binds each key and two over a list unpack each item, as in Jinja2, so `{% for k, v in mapping\|dictsort %}` binds the key and the value (since 2.9.3; before, one variable over a mapping bound each value and two over a list bound the index and the item). `{% for k, v in mapping %}` gives the key and the value without `.items()` (see [Behavioural differences](#behavioural-differences)). Loop variables containing `.` are rejected (prototype-chain guard). |
| `block` / `endblock` | Yes | Named block for template inheritance. |
| `extends` | No | Dynamic parent (`{% extends var %}`, `{% extends full if cond else partial %}`) resolves on the [async render path](../swig/loaders#async-loaders); the synchronous path requires a string literal. See [Non-Goals](./non-goals#dynamic-extends). |
| `include` | No | Supports `with context` (default), `without context`, and `ignore missing`. |
| `macro` / `endmacro` | Yes | Positional parameters with defaults (`{% macro f(a, b="x") %}`); defaults may reference earlier parameters or be full expressions. Keyword-argument **calls** are not supported — see [Non-Goals](./non-goals#macro-kwargs). |
| `import` | No | `{% import "forms.jinja2" as f %}{{ f.label("x") }}`. Path must be a string literal. |
| `from` | No | `{% from "forms.jinja2" import label, shout as yell %}`. Path must be a string literal. |
| `raw` / `endraw` | Yes | Verbatim content; variable, tag, and comment syntax pass through untouched. |
| `filter` / `endfilter` | Yes | Pipes the block's output through a filter chain (`{% filter upper %}…{% endfilter %}`, `{% filter lower\|upper %}`). |
| `with` / `endwith` | Yes | Pushes a fresh local scope with named assignments (`{% with x = 5, y = a + 1 %}`). |
| `autoescape` / `endautoescape` | Yes | Override autoescape for a region. Accepts a literal `true`/`false` only. |

¹ `set` is `endset`-terminated only in body form.

Tags explicitly **not implemented** (throw at parse time): `{% call %}`, `{% do %}`, `{% trans %}`. See [Non-Goals](./non-goals#unsupported-tags) for the rationale and error messages.

## Filters

`@rhinostone/swig-jinja2` ships 39 built-in filters (42 callable names counting the `e`, `count`, and `d` aliases). They live in `packages/swig-jinja2/lib/filters.js`. Every filter below was cross-checked against Python Jinja2 3.x.

Since 2.9.13 a filter whose input is `undefined` or `null` no longer fails or prints `undefined`, `null` or `[object Object]`: a filter after a filter or a call that found nothing renders an empty string (`{{ items|first|lower }}` over an empty list, `{{ fn()|upper }}`), and `truncate`, `indent`, `center`, `urlencode`, `striptags` and `title` read such an input as an empty string, where Jinja2 writes `None` for a `None` value.

### Strings & formatting

| Filter | Arity | Notes |
| --- | --- | --- |
| `upper` / `lower` | 0 | Case conversion. Recurse into arrays / objects. |
| `capitalize` | 0 | First character upper, rest lower. Recurses into arrays / objects. |
| `title` | 0 | Title-case each word. Word boundaries: whitespace and `- ( [ { <`. Recurses into arrays / objects. |
| `trim` | 0/1 | Strip surrounding whitespace, or a given character set, from both ends. |
| `truncate` | 1–4 | Truncate to a length with an ellipsis; word-boundary aware unless `killwords`. |
| `replace` | 2/3 | Literal substring replace with optional count — **matches Python Jinja2** (`replace(old, new, count)`), not the Twig object-map form. |
| `striptags` | 0 | Strip tags/comments, collapse whitespace to single spaces, trim. Recurses into arrays / objects. |
| `format` | N | `printf`-style — `%s %d %i %u %f %F %e %E %g %G %x %X %o %c %%`, with flags (`-` `+` space `0`), width, and `.precision`. The exponent and `%g` forms print as Python's do. |
| `wordcount` | 0 | Count `\w+` runs. `0` for `undefined` or `null` (since 2.9.13; before, `1`). |
| `wordwrap` | 1–3 | Greedy word-wrap to a width; breaks over-long words by default. A width of 0 or less returns the text unchanged, where Jinja2 raises. |
| `indent` | 1–3 | Indent each line; first line and blank lines skipped unless `first`/`blank`. |
| `center` | 1 | Center within a field width (extra space on the right). |
| `urlencode` | 0 | Percent-encode a string (preserves `/`), or encode a mapping/pair-list as a query string. |
| `escape` / `e` | 0/1 | HTML-escape (default) or `escape("js")`. |
| `safe` | 0 | Mark a value safe (bypass autoescape). |

### Sequences & mappings

| Filter | Arity | Notes |
| --- | --- | --- |
| `first` / `last` | 0 | First / last item of an array, string, or mapping. |
| `join` | 0/1 | Join with a glue string (default empty, the Jinja2 default — not a comma). |
| `length` / `count` | 0 | Length of an array/string, or key count of a mapping. `0` for `undefined`, `null` and an empty string (since 2.9.13; before, an empty string). |
| `reverse` | 0 | Reversed copy (does not mutate). |
| `sort` | 0/1 | Sorted copy; pass a truthy argument for descending. |
| `list` | 0 | Coerce to a list — string → characters, mapping → keys. |
| `unique` | 0/1 | Unique items, first-seen order; case-insensitive for strings by default. |
| `batch` | 1/2 | Chunk into rows of N; optional pad value for the last row. A size above 1,000,000 leaves the last row unpadded (since 2.9.2). |
| `slice` | 1/2 | Distribute across N columns (the inverse of `batch` — distinct from the `seq[::]` subscript). More than 1,000,000 columns give an empty list (since 2.9.2). |
| `dictsort` | 0–3 | Sort a mapping into `[key, value]` pairs by key (or value), case-insensitive by default. |
| `groupby` | 1 | Group a sequence of objects by a (dotted) attribute into `{ grouper, list }` records. |
| `min` / `max` | 0/1 | Smallest / largest item; case-insensitive string compare by default. |
| `sum` | 0–2 | Sum a sequence, with optional dotted `attribute` and `start`. |
| `random` | 0 | A random item (non-deterministic). |

On a mapping, `first`, `last`, `min`, `max`, `reverse`, `unique`, `sort`, `list`, `join`, `slice` and `batch` use its keys, as Jinja2 iterates a mapping. `sum` adds a mapping's values and `random` returns the mapping unchanged, where Jinja2 raises. `sort` and `batch` take a string by its characters.

### Numbers & values

| Filter | Arity | Notes |
| --- | --- | --- |
| `abs` | 0 | Absolute value. |
| `round` | 0–2 | Round to a precision; method `common` (default), `ceil`, or `floor`. |
| `int` | 0–2 | Parse an integer with a default and optional base. |
| `float` | 0/1 | Parse a float with a default. |
| `default` / `d` | 1/2 | Fallback value — see [Behavioural differences](#behavioural-differences) for the empty-string case. |
| `tojson` | 0/1 | JSON-serialize, HTML-safe. Marked safe. |
| `date` | 1–3 | PHP-style format tokens via the shared `@rhinostone/swig-core` date formatter. A swig-family extension — Jinja2 core has no `date` filter. A missing, `null`, empty or invalid value gives an empty string (since 2.9.13; before, `NaN`, or 1970 for a filter or call result of `null`). |

### Safe filters

These bypass autoescape (the autoescape `e` tail is not appended): **`safe`** and **`tojson`**. **`escape`** / **`e`** is not marked safe, but `{{ x|e }}` is still escaped once, not twice, because the HTML escape is idempotent. Everything else is escaped on output — note that `urlencode` is **not** safe (unlike native swig's `url_encode`), so a mapping rendered to a query string has its `&` escaped to `&amp;` on output. Filters that emit already-safe HTML you register yourself must set `.safe = true` on the function.

### Registering your own

```js
jinja2.setFilter('exclaim', function (input) { return String(input) + '!'; });
jinja2.render('{{ msg|exclaim }}', { locals: { msg: 'hi' } });
// → "hi!"
```

```js
function monospace(input) { return '<code>' + input + '</code>'; }
monospace.safe = true;
jinja2.setFilter('monospace', monospace);
```

See [Extending Swig](../swig/extending) for the full filter/tag extension contract — it is identical across frontends.

## Behavioural differences

These behaviours are **supported** but diverge from Python Jinja2 because the JavaScript runtime (or the shared swig-core engine) differs from CPython. None of them throw — they just behave differently:

| Area | Python Jinja2 | `@rhinostone/swig-jinja2` |
| --- | --- | --- |
| `default` on `""` | Keeps the empty string (only `undefined` triggers fallback without `boolean=true`). | Falls back, because a missing variable arrives as `""` after engine coercion. Real falsy values `0` / `false` are preserved; pass `true` as the second argument to fall back on any falsy value. |
| Macro output | Returns a `Markup` object (not re-escaped). | Autoescaped like any other `{{ … }}` output. Wrap in `\|safe` for trusted HTML. |
| `{% for k, v in mapping %}` | Requires `.items()`. | Iterates the mapping directly (key, value) — `.items()` is not available. |
| `{% for k, v in items %}` where an item does not hold two values | Raises a `ValueError` (too many or not enough values to unpack), or a `TypeError` for an item that is not iterable. | Binds what the item holds (since 2.9.3): a missing value renders empty, extra values are ignored, and an item that is not a list, a string or a mapping binds nothing. |
| `{% for x in a if c else b %}` | Raises `TemplateSyntaxError`: in a `for` tag, `if` starts a loop filter, so an inline-if iterable needs parentheses, `(a if c else b)`. | Also accepts it without the parentheses: it iterates `a` when `c` holds and `b` otherwise. |
| `+` on mixed types | `1 + "x"` raises `TypeError`. | Coerces (`"1x"`), JavaScript-style. Use `~` for explicit, intentional string concatenation. |
| A member or subscript of a missing value (`x.y` with `x` undefined, `users[0].name` with `users` empty) | Raises `UndefinedError`, as does arithmetic on a missing item (`users[0] * 2`); `users[0]` alone and `users[0]\|upper` render `""`, and `users[0] ~ "x"` gives `x`. | Renders `""` (for a subscript since 2.9.10; before, `users[0].name` failed with `Cannot read properties of undefined`), and in arithmetic a missing item reads as `""`: `users[0] * 2` gives `0` and `users[0] + 1` gives `1`. |
| `in` and `not in` | Python equality: `True in [1]`, `0 in [False]`, `[1, 2] in [[1, 2]]` and `None in [None]` are true and `1 in {'1': 'x'}` is false; an undefined variable is not `''`; `None in 'abc'` raises. | Membership as in Jinja2 since 2.9.0, except: a boolean and a number are different items, so `true in [1]` and `0 in [false]` are false; a list or a mapping inside a list matches only the same object, so `[1, 2] in [[1, 2]]` is false; a `null` or undefined variable tests like `""`, so it is in every string and in a list holding `""`, and not in a list holding `null`; a number tests a mapping key with the same digits, so `1 in {"1": "x"}` is true. |
| `is sequence` | A mapping is also a sequence. | An array or string only; a mapping is `is mapping`. |
| `with x = …` values | Evaluate against the enclosing scope. | Same — evaluated against the outer scope (object-literal merge, not sequential). |
| Imported macros | `{% import %}` is `without context` by default. | Imported/`from`-imported macros see the caller context (swig macro model — matches swig-twig). |
| `round` | Float-repr rounding (`42.55\|round(1)` → `42.5`). | Naive decimal rounding (`42.55\|round(1)` → `42.6`). |
| String filters on an array (`upper`, `lower`, `capitalize`, `title`, `striptags`) | Work on the list's string form: `['hELLO']\|capitalize` gives the string `['hello']`. | Apply to each element and return an array: `['hELLO']\|capitalize` gives the array `['Hello']`, which renders as `Hello`. |
| Rendering `true`, `false` and `null` | `True`, `False`, `None` — so `true\|urlencode` gives `True`, and a mapping with those values gives `a=True&b=None`. | `true`, `false`, and an empty string for `null` / `undefined`; `urlencode` gives `true` and `a=true&b=null`. |
| `none`, `None`, `True`, `False` | Constants. | Constants too (since 2.9.9; before, they were variable names that rendered as an empty string), and a template that binds one of them fails to compile. `none` renders as an empty string wherever a variable holding None does; `x == none` is true for an undefined variable, as `x is none` is, where Jinja2 gives false; and a None that a filter returns reaches the next filter as `null`, so `{{ x\|default(none)\|upper }}` renders `[object Object]` (Jinja2: `NONE`). |
| Characters outside the Basic Multilingual Plane, such as an emoji | Count as one character. | Count as two: `length` gives 2, and `first`, `last`, `list`, `reverse`, `sort`, `unique`, `truncate` and slicing can split one into invalid halves. |
| `is` tests on `null`, an undefined variable, a boolean or a value the test does not take, and `divisibleby(0)` | For example: `x is defined` is true for `None`; `even`, `odd` and `divisibleby` raise on anything but a number, and `divisibleby(0)` raises; `True is number` and `True is odd` are true; `lower` and `upper` test the string form of any value, so `{'a': 1}` or `1e300` is `lower`. | For example: `x is defined` is false and `x is undefined` true for `null`; for the other tests except `none`, a `null` or undefined variable tests like `""`, so `is string` is true for it, and `is iterable` and `is sequence` for `null`; `even`, `odd` and `divisibleby` return false on anything but a number, and `divisibleby(0)` returns false; `true is number` and `true is odd` are false; `lower` and `upper` are false for anything but a string. |

See [Migrating from Python Jinja2](./migration) for the porting view of these.

## Autoescape

Autoescape behaves as in native swig — `true` by default, applies the `e` filter last, honours `.safe = true` on filter exports. The built-in safe filters (`safe`, `tojson`) are excluded.

See [Security](../swig/security#what-the-guards-protect-against) for the full prototype-chain guard matrix — it applies uniformly across frontends because the guards live in `swig-core`'s shared backend.
